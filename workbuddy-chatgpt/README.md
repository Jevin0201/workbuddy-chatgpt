# WorkBuddy ChatGPT 0.4.3 预览版

独立 Windows 连接器，不需要 DSH。安装包包含 Node 运行时与网络依赖。

## 用户流程

安装 → WorkBuddy 设置 / 模型 → **登录ChatGPT** → 官方授权页面 → 模型列表。
每个模型有显示开关，修改后自动保存；推理档位通过 WorkBuddy 对话模型选择器的原生控件调节，不再把每个档位复制成一个模型。

## 安装与卸载

仅支持经过哈希校验的原版 WorkBuddy 5.9.3。退出 WorkBuddy，解压发布 ZIP，右键以管理员身份运行 Install.cmd。安装会明确提示 EXE 签名变化，并备份原文件。已装旧版按钮时，安装器会先核验旧版安装记录与原件备份，再迁移按钮；未知修改会阻止安装。不要手动覆盖或删除旧备份。

后台服务安装至 `%LOCALAPPDATA%\WorkBuddyChatGPT\app`，由当前用户的启动项启动，监听 127.0.0.1:43187；OAuth 回调监听 1455。没有固定代理要求；如需代理，在安装目录创建 settings.json：`{"proxyUrl":"http://127.0.0.1:你的端口"}`，然后重启该服务。

卸载：退出 WorkBuddy，以管理员身份在安装目录运行 uninstall.ps1。脚本恢复原 EXE/ASAR、删除本连接器启动项并停止本连接器进程。保留账号数据与原始文件备份。

账号凭据使用 Windows DPAPI CurrentUser 加密，位于 `%LOCALAPPDATA%\WorkBuddyChatGPT\account.dpapi`。不会读取 DSH、Codex 或其他应用的凭据。登录授权逻辑沿用既有 direct-scope 流程，仍需要真实账号验收；不能保证账号授予此 scope，也不能保证上游返回网页 ChatGPT 的完整模型列表。

## 开发与验证

`npm ci --ignore-scripts`；`npm test`；`node build.mjs`。

本版本仍为预览：尚未完成真实账号登录、安装后界面、开关热更新及对话档位的设备验收。WorkBuddy 本体升级后需要重新核对兼容性。原版支持的档位枚举可能少于账号返回的档位，不能把静态能力字段当作全部档位可选的运行时证明。文本、函数工具调用与 SSE 沿用现有转换器；附件尚未接入。

## 0.4.1 修复

模型列表仅显示模型名称；同步与升级时停用同模型的旧 DSH 重复项，使用户选中新账号条目及其原生思考档位。兼容账号接口遗漏 Content-Type 但返回合法 SSE 的响应，仍要求合法事件和完成事件。2026-11-10 使用已登录账号的 Terra 完成简短真实文本请求；完整工具任务和升级后的界面仍需用户确认。86 项回归测试通过。

## 0.4.3 登录失效修复

刷新接口返回 invalid_grant 时，显示中文重新登录指引，并将当前会话标记为需要登录，避免反复刷新已失效的凭据。网络错误保留 502 可重试状态。自动化回归 88 项通过，安装包解包与内置运行时校验通过。当前服务端拒绝的授权仍需用户重新登录。
